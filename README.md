# Bot Tài Xỉu Xịnh (bottxxin)

Bot Tài Xỉu nâng cao, có Flask giữ online trên Render.

## Tính năng
- Slash command
- Balance + History
- Top 10 người giàu
- Admin commands
- Flask keep alive (Render Free)

## Cài đặt
1. Clone repo
2. Tạo file `.env`
3. `pip install -r requirements.txt`
4. `python main.py`
